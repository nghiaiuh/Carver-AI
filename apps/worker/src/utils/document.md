# Utils Folder

## Vai trò

`utils/` chứa helper nhỏ, thuần, không mang trách nhiệm nghiệp vụ lớn.

## Mục đích

- helper log
- helper retry nhỏ
- helper mime / time / string nếu cần

## Flow ngắn

`utils/` chỉ hỗ trợ các lớp khác, không nên trở thành nơi gom business logic.

## Ghi chú Phase 1

Folder này hiện mới có tài liệu để giữ cấu trúc rõ ràng từ đầu.
